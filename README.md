## 🇧🇷 Português

**Terere** é um aplicativo desktop open-source desenvolvido em Python (Tkinter) focado no aprendizado, análise morfológica e prática do idioma Guarani.

### Principais Funcionalidades

* **Dicionário Flexível:** Consulte, adicione e edite verbetes livremente. Suporta bases de estudo independentes (Guarani ↔ Português e Guarani ↔ Espanhol).
* **Laboratório Morfológico:** Analisador e conjugador de palavras que identifica raízes e tempos verbais (Paradigma Areal, Aireal, Chendal) e substantivos triformes.
* **Sistema de Prática (SRS):** Quiz inteligente que adapta a frequência das perguntas com base no seu histórico de acertos e erros.
* **Teclado Inteligente:** Botões de atalho integrados para inserção rápida de caracteres específicos (ã, ẽ, ĩ, õ, ũ, ỹ, g̃, ñ) e oclusiva glotal (uso do puso ' ).
* **Gestão de Perfis:** Salve seu progresso, sequências de dias estudados e estatísticas localmente.
* **Temas Culturais:** Interface comutável entre o Tema Claro (Inspirado na flor do Tajy/Ipê) e o Tema Escuro (Noite nos Andes).

### Como Executar

1. Certifique-se de ter o Python 3 instalado.
2. Mantenha os arquivos modulares (`main.py`, `interface.py`, `modelos.py`, `config.py`, `utilitarios.py`) no mesmo diretório, juntamente com o arquivo de banco de dados `.csv` e o ícone `terere.png`.
3. Execute o comando no terminal:
`python main.py`

## 🇪🇸 Español

**Terere** es una aplicación de escritorio de código abierto desarrollada en Python (Tkinter) enfocada en el aprendizaje, análisis morfológico y práctica del idioma Guaraní.

### Características Principales

* **Diccionario Flexible:** Consulte, agregue y edite palabras libremente. Soporta bases de estudio independientes (Guaraní ↔ Español y Guaraní ↔ Portugués).
* **Laboratorio Morfológico:** Analizador y conjugador de palabras que identifica raíces y tiempos verbales (Paradigma Areal, Aireal, Chendal) y sustantivos triformes.
* **Sistema de Práctica (SRS):** Cuestionario inteligente que adapta la frecuencia de las preguntas según su historial de aciertos y errores.
* **Teclado Inteligente:** Botones de acceso rápido integrados para insertar caracteres específicos (ã, ẽ, ĩ, õ, ũ, ỹ, g̃, ñ) y la oclusiva glotal (uso del puso ' ).
* **Gestión de Perfiles:** Guarde su progreso, rachas de días estudiados y estadísticas localmente.
* **Temas Culturales:** Interfaz intercambiable entre el Tema Claro (Inspirado en la flor del Tajy/Lapacho) y el Tema Oscuro (Noche en los Andes).

### Cómo Ejecutar

1. Asegúrese de tener Python 3 instalado.
2. Mantenga los archivos modulares (`main.py`, `interface.py`, `modelos.py`, `config.py`, `utilitarios.py`) en el mismo directorio, junto con el archivo de base de datos `.csv` y el icono `terere.png`.
3. Ejecute el comando en la terminal:
`python main.py`

## 🇵🇾 Guarani

**Terere** ha'e peteĩ tembipuru komputadóra pe guarã ijypykuéva ijeheguíva, ojejapóva Python (Tkinter) rupive. Oñembosako'i ñañemoarandu, ñaha'ã ha ñamohesakã hag̃ua avañe'ẽ.

### Mba'eita Oguerekóva

* **Ñe'ẽndy:** Ikatu eheka, emoĩ ha emoingove ñe'ẽ pyahu. Oguereko ñe'ẽryru oñembohasáva (Avañe'ẽ ↔ Karaiñe'ẽ ha Avañe'ẽ ↔ Poytugañe'ẽ).
* **Ñe'ẽ Kuaaty:** Ñe'ẽ apoha ha moñe'ẽha ohechakuaáva ñe'ẽrapo ha ára (Ysaja Areal, Aireal, Chendal) ha tero mbohapy ysajáva (triformes).
* **Ñembosarái (SRS):** Porandu oñemoambuéva nde jejavy ha nde resape'a rupive.
* **Jekutyha:** Oguereko mba'endaha pya'e ikatu hag̃uáicha ehai umi tai tĩgua (ã, ẽ, ĩ, õ, ũ, ỹ, g̃, ñ) ha puso ( ' ).
* **Ava Ñongatuha:** Eñongatu ne rembiapo, umi ára eñemoarandúva ha ne rembiasa.
* **Sa'y:** Ikatu ñamoambue sa'y. Oĩ sa'y sakã (Tajy poty rehegua) ha sa'y ypytũ (Pyhare Andes-pe).

### Mba'éicha Oipuru

1. Emaña oĩha Python 3 nde komputadórape.
2. Emoĩ umi vore (`main.py`, `interface.py`, `modelos.py`, `config.py`, `utilitarios.py`) peteĩ ryrupe, oĩháme pe `.csv` ha pe ra'ãnga `terere.png`.
3. Emoñepyrũ terminal-pe:
`python main.py`
